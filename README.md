# Dragon Ball Mod

A Minecraft mod that includes all Dragon Ball transformations and constructions. This mod allows players to transform into various Dragon Ball characters and build iconic Dragon Ball constructions.

## Installation

1. Install Fabric Loader for Minecraft 1.20.1.
2. Place the mod jar in the mods folder.

## Usage

1. Launch Minecraft with the Fabric Loader installed.
2. Use the `/transform <transformation>` command to transform the player.
3. Use the `/build <construction>` command to build a construction.
